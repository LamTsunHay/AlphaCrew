--- FUNCTION: calculate_outcome_profile(matches: list) -> dict ---
If len(matches) < VECTOR_DB_MIN_SAMPLES:
  Return:
  {
    "confidence"    : "INSUFFICIENT",
    "sample_size"   : len(matches),
    "action"        : "SKIP_TRADE",
    "reason"        : "Insufficient historical samples for reliable probability estimate.",
    "win_rate_day1" : None,
    "win_rate_day3" : None,
    "expected_value": None,
    "suggested_stop": None,
    "suggested_target": None,
  }

Otherwise compute from matches list:
  day1_returns    = [m["day1_return"] for m in matches]
  day3_returns    = [m["day3_return"] for m in matches]
  adverse_moves   = [m["max_adverse_move"] for m in matches]

  winners_d3      = [r for r in day3_returns if r > 0]
  losers_d3       = [r for r in day3_returns if r <= 0]

  win_rate_d1     = mean of (r > 0 for r in day1_returns)
  win_rate_d3     = mean of (r > 0 for r in day3_returns)
  avg_gain        = mean of winners_d3 if any else 0
  avg_loss        = abs(mean of losers_d3) if any else 0
  loss_rate       = 1 - win_rate_d3
  expected_value  = (win_rate_d3 * avg_gain) - (loss_rate * avg_loss)

  confidence classification:
    >= 150 samples  → "HIGH"
    >= 80  samples  → "MODERATE"
    >= 40  samples  → "LOW"

  Return full dict:
  {
    "confidence"          : classified string,
    "sample_size"         : int,
    "action"              : "PROCEED" if expected_value > 0 else "SKIP_TRADE",
    "win_rate_day1"       : float rounded 4dp,
    "win_rate_day3"       : float rounded 4dp,
    "avg_gain_winners"    : float rounded 4dp,
    "avg_loss_losers"     : float rounded 4dp,
    "expected_value"      : float rounded 4dp,
    "avg_max_adverse"     : mean of adverse_moves rounded 4dp,
    "adverse_95pct"       : 95th percentile of adverse_moves rounded 4dp,
    "pct_held_above_21ema": mean of (m["held_above_21ema"] for m in matches) rounded 4dp,
    "suggested_stop"      : 75th percentile of adverse_moves (as negative float) rounded 4dp,
    "suggested_target"    : mean of winners_d3 rounded 4dp if any else None,
  }

--- FUNCTION: get_market_regime() -> dict ---
Download 60 days of SPY daily close via yf.download("SPY", period="60d")
Compute 50-day SMA on close prices.
Latest_close = most recent close.
Latest_sma   = most recent SMA value.
pct_above    = (latest_close - latest_sma) / latest_sma

Return:
{
  "regime"         : "BULLISH" if latest_close > latest_sma else "BEARISH",
  "spy_close"      : latest_close,
  "spy_sma50"      : latest_sma,
  "pct_above_50sma": pct_above,
}

--- FUNCTION: get_top_sectors() -> dict ---
Download 10 days of daily close for all 11 sector ETFs in SECTOR_ETFS plus SPY via yf.download()
For each sector ETF compute 5-day return: (close[-1] - close[-6]) / close[-6]
Compute SPY 5-day return same way.
Compute relative_5d = sector_5d_return - spy_5d_return for each sector.
Sort sectors by relative_5d descending.
Retain only top TOP_SECTOR_COUNT sectors.

Return:
{
  "top_sectors"     : list of top sector ETF tickers,
  "sector_rankings" : dict of {ticker: relative_5d_return} for all sectors sorted,
  "spy_5d_return"   : float,
}

--- FUNCTION: filter_by_sector(tickers: list, top_sectors: list) -> list ---
For each ticker, look up its sector using yf.Ticker(ticker).info["sector"]
Map sector name to ETF ticker using a local lookup dict matching SECTOR_ETFS values to keys.
Retain only tickers whose mapped ETF is in top_sectors list.
Return filtered list.

--- FUNCTION: apply_individual_gates(tickers: list) -> list ---
For each ticker download 220 days of daily price data via yfinance.
Compute:
  ATR14: 14-day average of (high - low)
  Price: latest close
  volatility_ratio: ATR14 / Price
  EMA21:  21-day EMA of close
  EMA200: 200-day EMA of close

Apply gates in order:
  VOLATILITY GATE: drop if volatility_ratio > VOLATILITY_CEILING_RATIO
  TREND GATE:      drop if Price <= EMA200 OR Price <= EMA21

Return list of surviving tickers with their computed metrics dict.

--- FUNCTION: apply_earnings_gate(tickers_with_metrics: list) -> list ---
Load earnings_calendar.csv into a dataframe (columns: ticker, next_earnings_date)
For each ticker check if next_earnings_date - today <= EARNINGS_EXCLUSION_DAYS calendar days.

Return filtered list.

--- FUNCTION: apply_sector_leadership_gate(tickers_with_metrics: list) -> list ---

--- FUNCTION: calculate_eass(eass_inputs: dict, catalyst_type: str) -> dict ---
Implement the 3-component EASS formula using weights from config.EASS_WEIGHTS.

COMPONENT 1 — analyst_surprise:
  If actual_eps and consensus_eps are both not None:
    raw = (actual_eps - consensus_eps) / abs(consensus_eps)
    Apply sandbagging_penalty = 0.0 (no history yet — set to 0 on first deployment)
    analyst_component = raw * (1 - sandbagging_penalty)
  Else:
    analyst_component = 0.0

COMPONENT 2 — whisper_surprise (FUTURE_STUB):
  whisper_component = 0.0
  # FUTURE_STUB: When whisper feed is added, implement whisper_surprise() here.
  # Weight in config.EASS_WEIGHTS["whisper_surprise"] is already set to 0.00
  # so this component has zero effect until activated.

COMPONENT 3 — guidance_delta:
  If guidance_raised is True:
    guidance_component = guidance_delta_pct if guidance_delta_pct > 0 else 0.10
  Elif guidance_cut is True:
    guidance_component = guidance_delta_pct if guidance_delta_pct < 0 else -0.15
    guidance_component *= 2.50   # Amplify negative guidance heavily
  Else:
    guidance_component = 0.0

raw_eass = (
    EASS_WEIGHTS["analyst_surprise"] * analyst_component +
    EASS_WEIGHTS["whisper_surprise"] * whisper_component +
    EASS_WEIGHTS["guidance_delta"]   * guidance_component
)

Normalize raw_eass to -10.0 to +10.0 scale:
  normalized = max(-10.0, min(10.0, raw_eass * 20))

Classify signal_quality:
  If analyst_component > 0 and guidance_component > 0  → "CONFIRMED_BULLISH"
  If analyst_component > 0 and guidance_component < 0  → "GUIDANCE_DESTRUCTION_RISK"
  If analyst_component < 0 and guidance_component < 0  → "CONFIRMED_BEARISH"
  If analyst_component > 0 and guidance_component == 0 → "ANALYST_BEAT_ONLY"
  Default                                              → "MIXED_SIGNAL"

Return:
{
  "eass_score"          : normalized float rounded 4dp,
  "analyst_component"   : analyst_component rounded 4dp,
  "whisper_component"   : 0.0,
  "guidance_component"  : guidance_component rounded 4dp,
  "signal_quality"      : string,
  "catalyst_type"       : catalyst_type,
  "raw_text_combined"   : eass_inputs["raw_text_combined"],
}

--- FUNCTION: apply_regime_strategy_mutator(audit_result: dict, regime: str) -> dict ---

  If audit_result["entry_strategy"] == "MARKET_OPEN":
    Mutate to "PULLBACK_LIMIT_21EMA"
  Multiply any position size by BEARISH_REGIME_MUTATOR
  Append "BEARISH REGIME: Position size reduced 50%, entry strategy downgraded." 
  to threats_identified list.
Return mutated audit_result.

--- FUNCTION: calculate_position_size(account_size: float, stop_distance_pct: float, regime: str) -> dict ---
risk_amount = account_size * STANDARD_ACCOUNT_RISK
If regime == "BEARISH":
  risk_amount *= BEARISH_REGIME_MUTATOR
shares = risk_amount / (account_size * stop_distance_pct) if stop_distance_pct > 0 else 0
Return:
{
  "risk_amount_dollars" : round(risk_amount, 2),
  "stop_distance_pct"   : round(stop_distance_pct, 4),
  "suggested_shares"    : int(shares),
  "regime_applied"      : regime,
}
